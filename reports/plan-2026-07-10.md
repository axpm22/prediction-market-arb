## Phase 1 — Non-sports matching pipeline (weeks 1–2, ~15–20h)

The centerpiece. Design principle: **deterministic structure first, AI second,
human always the gate** (rule 11 verbatim).

### 1.1 Data survey (~3h)
- Revive `kalshi.refresh_series_cache` (currently dead code) and record the
  non-sports series catalog for `nonsports.kalshi_categories`
  (Politics / Economics / Climate and Weather) into `data/kalshi_series.json` +
  a test fixture.
- Dump PM Gamma events per `nonsports.polymarket_tags` (politics, economy,
  weather) — one recorded fixture per tag.
- Deliverable: inventory report — market counts, strike structures, depth
  distribution per category. This tells us within days whether the lane has
  enough surface to matter.

### 1.2 Deterministic blocking-key matcher (~6h)
New module `arb/nonsports/match.py` (<200 lines):
- Blocking key = `(category, resolution-date window, numeric strike if present,
  canonical entity token)`. Kalshi non-sports tickers are templated (series +
  strike + date); PM carries `endDate` + tags + title entities.
- Econ (CPI, Fed, jobs) and weather (temperature strikes) pair near-
  deterministically on `(series-concept, date, strike)`. Politics needs the
  entity token (candidate/party) — still deterministic for the big markets.
- **No fuzzy text matching, ever** (the doctrine that killed V1's tennis edges).
- Output: candidate pairs with a `block_reason`; unmatched markets logged with
  why (left-on-table philosophy applied to matching).
- Tests from the recorded fixtures only.

### 1.3 Ground truth, manual-first (~4h, human-in-the-loop: you)
- Hand-verify 50–100 candidate pairs (and ~30 deliberate negatives) into
  `data/nonsports_map.yaml`. Manual entries are immediately usable by the
  matcher (rule 11's trusted path).
- This set **is** the §18.5 ground-truth prerequisite that currently blocks
  `ai_matcher.enabled`.

### 1.4 Haiku classifier stage (~5h)
- Runs only on blocked candidate pairs NOT already in the map; strict JSON
  verdict {same_event: bool, confidence, reason}; `min_confidence: 0.85`;
  `max_new_pairs_per_day` budget; verdicts cached in an append-only
  `ai_verdicts` table (schema MIGRATION_5 — ADDs only).
- **Pre-register the acceptance threshold before scoring** (amendment): enable
  the lane only if precision on the held-out ground truth ≥ 0.95 with zero
  false-positive pairs among proven-basket candidates.
- AI-matched pairs: always `status=REVIEW`, tagged `ai_matched`, segregated
  lane, never headline, settlement mismatch ⇒ permanent pair ban — all already
  enforced by `classify()`; verify with tests, don't re-implement.

### 1.5 Wire into detection (~3h)
- Matched cross-venue non-sports pairs → shared `event_key` → the existing
  XSPREAD path (REVIEW-only forever until the §18.2 gate — correct for
  measurement).
- Same-venue negrisk/political need no matching at all — 1.5 is strictly
  additive.

**Exit criteria:** inventory report; matcher green on fixtures; ≥50-pair ground
truth; Haiku precision measured against the pre-registered bar; matched pairs
producing quotes in a dry-run scan.
